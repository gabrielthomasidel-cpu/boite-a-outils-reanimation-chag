COMMANDES RÉANIMATION 2.7.0 — VERSION HTML

Ouvrir index.html dans Microsoft Edge (ou Chrome). Sous Windows, utiliser le
raccourci installé : il active l'enregistrement dans C:\commandes.

Organisation des fichiers
  index.html                         accueil et état des commandes en cours
  Commande_*.html                    pages des trois modules (quelques lignes)
  css/commandes.css                  feuille de style unique (thèmes clair et sombre)
  js/modules.js                      configuration et différences entre modules
  js/app-shell.js                    structure d'écran et mode d'emploi
  js/core/                           code métier commun aux trois modules
  catalogues/<module>.js             catalogues livrés (données uniquement)
  img/                               icônes vectorielles
  vendor/                            bibliothèques embarquées (pdf-lib, SheetJS, QR)
  Listes_papier/                     listes vierges du mode dégradé

Les comptages sont conservés automatiquement sur le poste. Exportez
régulièrement une sauvegarde JSON du catalogue (Gestion du catalogue).
Ne saisissez aucune donnée de patient.

Mode dégradé : le bouton « Liste papier » de chaque module ouvre une liste
vierge A4 à remplir à la main. Rééditez-la après une modification du
catalogue. Aucune synchronisation automatique avec l'application.
