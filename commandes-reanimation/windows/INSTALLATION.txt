COMMANDES RÉANIMATION — WINDOWS 10 64 BITS

1. Double-cliquez sur Commandes_Reanimation_Setup_2.6.2.exe.
2. Suivez l'assistant en français. Aucun droit administrateur n'est requis.
3. Ouvrez Commandes Réanimation depuis le Bureau ou le menu Démarrer.

Microsoft Edge doit être installé. L'application s'ouvre directement en plein
écran dans Edge. Le bouton du bandeau permet de basculer en mode fenêtré et de
revenir en plein écran. Utilisez Quitter afin de terminer les sauvegardes
programmées avant la fermeture. Les fichiers fournis sont intégrés pour une utilisation
hors connexion : trois modules, catalogues, exports et listes papier PDF.

Les données de cette édition sont conservées dans un profil dédié :
%LOCALAPPDATA%\CommandesReanimationWin64\Profil
La désinstallation conserve ce profil. Les données d'une ancienne édition
ou d'un navigateur ne sont pas reprises automatiquement : exportez-les au
format JSON dans l'ancienne édition puis importez-les dans celle-ci.
Effectuez régulièrement une sauvegarde JSON de vos données.

L'installateur n'est pas signé numériquement.
La compatibilité Windows 10 est ciblée ; les opérations métier et les
périphériques doivent être validés sur le poste de destination.

Les trois modules proposent le format d'étiquette « Avery plastifié »
(Avery L7060 : 21 étiquettes de 63,5 × 38,1 mm sur une page A4).

Consultez le bouton ? de chaque module pour l’aide Windows et la rubrique Avertissement et sécurité. Les précautions sont également disponibles dans web/SECURITE.txt.


Sauvegarde automatique Windows
Les dossiers C:\commandes\Pharmacie, C:\commandes\Solutés et C:\commandes\Magasin sont créés au lancement. Chaque module utilise Application (catalogues et HTML), Sauvegardes (commandes enregistrées), Etiquettes (planches QR et codes-barres), Archives (PDF de commande et anciennes versions remplacées). Lancez le programme avec son raccourci Windows pour activer ces enregistrements. Le compte Windows doit pouvoir écrire dans C:\commandes. Aucun choix de dossier n’est nécessaire.
